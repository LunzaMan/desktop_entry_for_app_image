# Create desktop entry for App Images Automatically

A small script to create desktop entry for AppImages Automatically. 

## Installing and Usage
1. Clone the repo
```bash
  git clone LunzaMan/desktop_entry_for_app_image
  cd sign-linuwu-sense-with-secure-boot
```

2. Give permission to the script
```bash
  chmod +x imageToApp
```

3. Run the script
```bash
  sudo imageToApp <path-to-app-image>
```
